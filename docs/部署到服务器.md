## ★ 关键坑:Camoufox 二进制下载(GitHub 被墙)

`camoufox fetch` 从 `github.com/daijro/camoufox/releases/download/...` 下 713MB,**服务器和本地都
≈0 B/s**(GitHub 对象 CDN 在国内被限速;注意 `git`/`api.github.com` 是另一通道,正常)。

**镜像实测(2026-05-31,服务器侧)**:GitHub 直连 / camoufox-CDN / ghfast.top → **全部 ≈0 B/s**;
**`gh-proxy.com` → 24 MB/s ✅**。所以用 gh-proxy.com。camoufox 0.4.11 要的确切版本用它自己解析:
`.venv/bin/python -c "import camoufox.pkgman as pk; print(pk.CamoufoxFetcher().url)"`。

```bash
# 在服务器:
GH=https://github.com/daijro/camoufox/releases/download/v135.0.1-beta.24/camoufox-135.0.1-beta.24-lin.x86_64.zip
# camoufox 缓存软链到数据盘(避免吃 14G 系统盘)
mkdir -p /mnt/data1/full-self-crawl-agent-beta/.camoufox-cache
ln -sfn /mnt/data1/full-self-crawl-agent-beta/.camoufox-cache /root/.cache/camoufox
curl -sL --max-time 110 -o /mnt/data1/full-self-crawl-agent-beta/.cf.zip "https://gh-proxy.com/$GH"
unzip -t .cf.zip >/dev/null && echo OK                 # 完整性校验(712MB)
rm -rf /root/.cache/camoufox/* && unzip -q -o .cf.zip -d /root/.cache/camoufox
echo '{"version": "135.0.1", "release": "beta.24"}' > /root/.cache/camoufox/version.json
chmod -R 755 /root/.cache/camoufox && rm .cf.zip
.venv/bin/python -c "import camoufox.pkgman as pk; print(pk.launch_path())"  # → .../camoufox-bin(不报错即成)
```

> ⚠️ 验证要用 `pk.launch_path()` 而非 `installed_verstr()`——后者只读 version.json 就报版本,
> 二进制没装也会"假成功"(踩过这个坑)。`launch_path()` 真查二进制存在。
> 以后服务器从 GitHub 下大文件,套 `https://gh-proxy.com/<github-url>`(ghfast.top 在此服务器不通)。

## 运维须知

- **磁盘铁律**:系统盘 `/` 只剩 14G。所有大东西(浏览器缓存、artifacts)都已引到数据盘;
  别往系统盘写大文件,别再装大的 apt 包。
- **human-assist**:headed + noVNC 下你能真点登录;无人值守时 10 分钟自动超时(已实现)。
- **首登站点**:第一次 noVNC 进去手动登一次,cookies 存进 `artifacts/_profiles/{domain}/`,之后复用。
- **共享机器**:apt 装包时若撞 dpkg 锁(别人在 apt),等锁释放;docker 源偶尔握手失败会拖慢
  `apt update`,需要时临时 `mv /etc/apt/sources.list.d/docker.list /tmp` 再恢复。
